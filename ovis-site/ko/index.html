사용 방법

Ovis는 내 컴퓨터가 띄운 herdr web UI를 엽니다. 중간에 거치는 서버가 없습니다.

  1. PC에서 herdr web UI 실행

    무료 오픈소스입니다. Linux와 macOS는 명령어 하나로 모두 설치됩니다. Windows와 다른 설치 방법은 herdrweb.dev에 있습니다.

    curl -fsSL https://herdrweb.dev/install.sh | sh

  2. 휴대폰 연결

    PC에서 설정 → 폰 및 기기를 열고 Ovis로 QR 코드를 찍거나, 보이는 주소를 입력합니다.

  3. 어디서든 답하기

    승인 요청과 질문이 누르기만 하면 되는 카드로 옵니다. 에이전트의 터미널도 한 번 누르면 열리고, Esc·Tab·Ctrl 키 막대가 있습니다.

둘러보기

브라우저에서 쓰던 그 앱을 휴대폰에 맞게 만들었습니다.

코드는 내 PC에만 있습니다

계정 없음

가입할 것이 없습니다. 휴대폰을 PC와 한 번 연결하면 끝입니다.

PC와 바로 연결

앱은 내가 추가한 PC하고만, Tailscale이나 집 Wi-Fi 같은 내 네트워크로 통신합니다. 중간에 Ovis 서버가 없습니다.

추적 없음

광고도, 분석 도구도, 추적도 없습니다. 무엇을 저장하는지는 개인정보처리방침에 그대로 적었습니다.

자주 묻는 질문

herdr가 뭔가요?

herdr는 코딩 에이전트용 터미널 멀티플렉서입니다. Claude Code, Codex 같은 에이전트를 여러 칸에 나란히 띄워 돌립니다. herdr web UI는 그 칸들을 브라우저로, Ovis는 휴대폰으로 가져옵니다.

Tailscale이 꼭 필요한가요?

아니요. 다만 가장 쉬운 방법입니다. 휴대폰에서 PC로 갈 길만 있으면 됩니다. Tailscale, VPN, 같은 Wi-Fi, 직접 둔 HTTPS 프록시 모두 됩니다. 휴대폰 설정 안내(영어)에 방법별로 나와 있습니다.

무료인가요?

네. Ovis와 herdr web UI 모두 무료이고, herdr web UI는 MIT 라이선스 오픈소스입니다.

PC 없이 먼저 써 볼 수 있나요?

네. 연결 화면에 가상의 에이전트와 터미널로 된 데모가 있습니다. 휴대폰 밖으로 아무것도 나가지 않습니다.

어떤 휴대폰에서 되나요?

iPhone과 Android 모두 됩니다. 두 앱 모두 테스트 중이고, 곧 App Store와 Google Play에 나옵니다.
